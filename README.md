# Synapse AI 🤖

Synapse is a web-first AI chatbot built for Meisophant Digital Services using **Gemini API** and **Groq API**.

It provides fast, intelligent, and human-like conversations through a modern web interface.

---

## 🚀 Features

- AI-powered chat (Gemini)
- Ultra-fast inference (Groq)
- Conversation memory
- Web-based chat UI
- Mobile friendly
- Scalable architecture
